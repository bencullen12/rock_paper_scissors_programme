# rock_paper_scissors_programme
A basic rock paper scissors game in python

# Version 1
Uses a very basic system with if and elif loops for every outcome of a rock paper scissors game. Has 5 runs through of the game and doesn't record what the score would be.

# Version 2
Updates the code to incorporate a scoring system for wins, loses and ties. It runs through a best of 5 games. If it is a tie after these 5 games it goes to sudden death, continuing to run the game code until a winner is found. I also accounted for if a user does not input a correct option of rock, paper or scissors, rather than just returning an error message. 

# Version 3 
Updated the code further to use functions rather than just if/elif loops. The function for play_game() can be called at any time so we do not have to repeat the same code for the sudden death element of the game. The scoring system is still in place so we know how many wins each player has in the best if five series. On this final version, v3, we have a more compact code that is easier to follow when compared to v2.
